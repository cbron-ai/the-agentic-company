# Workflows

A workflow is a repeatable process with a trigger, owner, bounded steps, inputs, outputs, approval gates, failure paths, and evidence.

Every workflow should include:
- purpose and trigger;
- accountable human owner;
- prerequisites and data/tool scope;
- steps and responsible roles;
- acceptance criteria;
- approval points;
- failure and rollback paths;
- audit artifacts and metrics.
