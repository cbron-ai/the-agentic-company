# Financial Controls and Real Economics

AI operations create costs through model usage, subscriptions, cloud infrastructure, storage, email/messaging, payment fees, software licenses, refunds, support, and human review.

## Track four categories

- **Cash costs:** invoices, metered API charges, subscriptions, hosting, and vendor fees.
- **Allocated costs:** a reasonable share of flat-rate subscriptions and shared infrastructure assigned to projects.
- **Opportunity cost:** Board time spent approving, correcting, debugging, and supporting the system.
- **Risk cost:** expected losses from errors, outages, privacy incidents, chargebacks, and customer harm.

Never report an unmeasured subscription allocation as zero. Label it as an estimate and document the allocation method.

## Budget policy

Each project defines an owner, purpose, vendors, spend categories, per-run and monthly limits, alert thresholds, hard stops, renewal dates, and exception authority. Agents cannot approve their own budget increases or initiate unbounded purchases.

A cap that counts only metered API charges is a metered-spend cap—not a total-cost cap.

## Measure business value

Track customer outcomes, revenue collected, gross margin, retention, acquisition cost, cost per accepted deliverable, defect/rework rate, cycle time, and Board hours. Agent count, tokens, and completed tasks are diagnostics, not success metrics.
