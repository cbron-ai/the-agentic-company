# Roadmap

This roadmap is directional. A checked item means repository content exists; it does not mean an end-to-end production deployment has been proven.

## Phase 1 — Coherent companion foundation

- [x] Define Human Board / Muse AI CEO / Claude Shadow / specialist worker model
- [x] Align charter, decision rights, authority matrix, and role contracts
- [x] Add workflows and reusable Board records
- [x] Add JSON schemas and example configuration
- [x] Add Node-based schema validation and CI workflow
- [ ] Run an independent first-time-user walkthrough
- [ ] Verify every book-to-repository cross-reference

## Phase 2 — Book and starter-kit validation

- [ ] Reconcile manuscript terminology and decision rights with the canonical operating model
- [ ] Add a reproducible case study with baseline, method, sample size, costs, outcomes, failures, and limitations
- [ ] Conduct technical review of security, approval, and deployment guidance
- [ ] Test the starter kit with target readers and record setup friction
- [ ] Complete human copyedit, fact-check, and print/ebook layout review

## Phase 3 — Tested runtime adapters

- [ ] Select one runtime based on reader evidence, not trend
- [ ] Implement a minimal supervised workflow
- [ ] Test permission boundaries, approvals, stop/revoke, and recovery
- [ ] Publish tested versions and known limitations

## Phase 4 — Optional tooling

- [ ] Configuration validation CLI
- [ ] Durable approval and decision records
- [ ] Optional visual operating dashboard

## Non-goals

- Building another general-purpose agent framework
- Treating an AI as a legal officer or fiduciary
- Claiming profitability without customer and financial evidence
- Adding roles or infrastructure without demonstrated need
