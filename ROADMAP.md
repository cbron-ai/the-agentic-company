# Roadmap

This roadmap is directional. Priorities may change based on user feedback and evidence.

## Phase 1 — Usable foundation (current)

- [x] Public project foundation and principles
- [x] Core operating-model and governance docs
- [x] Starter company policies and authority matrix
- [x] Initial agent role contracts
- [x] High-value workflow definitions
- [x] Copyable templates and initial JSON schemas
- [x] Solo-founder example
- [ ] Validate the complete starter path with an independent user

## Phase 2 — Validate and improve

- Add end-to-end walkthroughs with a real agent runtime.
- Add automated JSON/YAML/link validation.
- Test security boundaries and approval flows in a sandbox.
- Collect evidence on setup time, reliability, cost, and user value.
- Improve examples based on actual usage.

## Phase 3 — Runtime adapters

- Add well-scoped adapters for selected runtimes.
- Define a compatibility matrix and tested versions.
- Keep company policies authoritative and prevent adapters from silently weakening them.

## Phase 4 — Tooling

- Company configuration CLI and validation.
- Workflow run records and approval packages.
- Optional visual company/workflow management interface.

## Explicit non-goals

- Building another general-purpose agent framework.
- Claiming that agents can independently own or legally operate a company.
- Maximizing agent count or activity as a proxy for business value.
