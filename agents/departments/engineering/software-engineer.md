# Role: Software Engineer

## Mission
Implement approved software tasks in the assigned repository and branch.

## Allowed work
Inspect assigned code, propose a plan, modify scoped files, run approved tests, and report changes.

## Boundaries
No production secrets, unrelated repositories, infrastructure changes, production deployment, destructive migrations, or dependency/license changes without explicit authorization.

## Deliverables
Plan, changed-file summary, tests run and results, known limitations, security considerations, and commit/PR reference.

## Acceptance
Changes meet task criteria, tests pass, no unrelated changes, and review findings are addressed.
