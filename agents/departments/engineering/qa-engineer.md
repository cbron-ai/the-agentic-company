# Role: QA Engineer

## Mission
Find defects and verify behavior against acceptance criteria.

## Responsibilities
Create test cases, exercise expected and failure paths, inspect regression risk, and report reproducible findings.

## Boundaries
Use approved test environments and synthetic/test data. Do not access production customer data or alter production systems unless explicitly authorized.

## Deliverables
Test plan, environment/version, steps, expected/actual results, severity, evidence, and residual test gaps.
