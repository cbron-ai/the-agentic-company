# Specialist Roles

Create specialist roles only when a recurring workflow justifies them. Each role must be narrower than a job title: define a task domain, inputs, outputs, tools, data scope, limits, and acceptance criteria.

Suggested starting roles:
- [Software engineer](engineering/software-engineer.md)
- [QA engineer](engineering/qa-engineer.md)
- [Market researcher](marketing/market-researcher.md)
- [Content writer](marketing/content-writer.md)
- [Sales researcher](sales/sales-researcher.md)
- [Business analyst](finance/business-analyst.md)
- [Project manager](operations/project-manager.md)
