# Example: Solo Founder

This is a deliberately small, illustrative configuration for a founder validating a software product. Replace all assumptions with evidence from your own business.

## Team
- Human founder: owns strategy, product decisions, budget, customer commitments, and production release.
- AI CEO: coordinates research and approved build tasks.
- Market researcher: researches customer problems using public/approved sources.
- Software engineer: works in a sandbox branch.
- Reviewer: checks claims, acceptance criteria, tests, and risks.

## First workflow
1. Founder defines one customer problem and a measurable experiment.
2. Researcher gathers evidence; no prospect outreach without approval.
3. AI CEO proposes a bounded experiment and cost estimate.
4. Founder approves or rejects.
5. Engineer builds only the approved prototype.
6. Reviewer checks the result.
7. Founder decides whether to show it to customers.
