# Solo Company Example

This example demonstrates the minimum operating model:

1. One human Board member.
2. Muse as AI CEO.
3. Claude as Shadow of the Board.
4. One specialist worker.
5. One customer problem and one bounded project.
6. Written charter, decision records, approval packages, cost tracking, and a tested stop procedure.

The example is illustrative. Replace placeholders with real customer evidence and measured economics before relying on it.
